# Projeto-Sprint-5
      Este projeto é um aplicativo interativo desenvolvido com Streamlit para análise de dados de vendas de veículos. A aplicação permite explorar os dados de forma visual e intuitiva por meio de gráficos dinâmicos com Plotly. O objetivo é facilitar a identificação de padrões no mercado de carros usados e apoiar a análise de preços e tendências de venda.
